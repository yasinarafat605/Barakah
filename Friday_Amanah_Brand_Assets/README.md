# Friday Amanah — Brand Asset Package

## Included
- Primary, horizontal, stacked, compact and icon-only logo versions
- Transparent and white-background PNG logo exports
- Dark and light app icons from 16×16 to 1024×1024
- Multi-size ICO favicon files
- PWA, Android and Apple web icons
- Five approved icon background variations
- Brand banner, feature strip, palette reference and complete brand board
- JSON and CSS colour tokens

## Approved colours
- Midnight Navy: #0A1D37
- Deep Emerald: #087A62
- Emerald Green: #10A981
- Fresh Mint: #38D3A5
- Trust Gold: #D2A74B
- Mint White: #EAF8F3
- Cloud White: #F8FAFC
- Charcoal Text: #1F2937

## Recommended use
- Dark app icon: Android, iOS, PWA and social profile
- Light app icon: light promotional layouts
- Transparent horizontal logo: website headers and documents
- Transparent stacked logo: square promotional layouts
- Icon-only transparent logo: watermarks and flexible branding
- Gold should remain a small accent, not a dominant interface colour

## Production note
These exports were separated from the approved AI-generated brand board and enlarged with high-quality Lanczos resampling. They are high-resolution raster assets, not native vector artwork. A designer should redraw the final approved mark in Figma, Illustrator or another vector editor before very large-format printing or trademark master-file delivery.
